# ĀIRA — Saree Studio Demo

Responsive static saree styling demo with the supplied model portrait.

Open `index.html` or run `python3 -m http.server 8000`.

GitHub Pages: https://nagasai17bce-rgb.github.io/virtualtryon/

The garment overlays are illustrative colour/fabric layers, not AI garment segmentation or photorealistic body-aware draping. Connect a VTON model/API for realistic try-on.
